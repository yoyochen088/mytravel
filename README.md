# 🗺️ 旅遊助手 PWA

個人旅遊行程管理 PWA，手機友善，可安裝到 iOS/Android 主畫面當 APP 使用。

## 功能

- **現在行程** - 根據當前時間自動顯示你現在應該在哪、下一站去哪
- **時間軸** - 查看每天的完整行程，可切換日期
- **美食清單** - 獨立的美食列表，支援分類篩選與隨機推薦
- **隨機探索** - 彈性景點依分類隨機推薦
- **一鍵導航** - 根據你的 GPS 位置，開啟 Google Maps 規劃路線
- **離線支援** - Service Worker 快取，離線也能查看行程

## Google Sheets 設定

### 前置步驟：
1. 建立一個 Google Sheets
2. 右上角「共用」→「知道連結的人都可以檢視」
3. 複製試算表網址，貼到 APP「設定」頁面即可

## 部署方式

推薦使用 GitHub Pages（免費、不休眠）：

1. GitHub 建立新 repo（Public）
2. 上傳所有檔案
3. Settings → Pages → Branch 選 main → Save
4. 等 1-2 分鐘，網站就上線了

網址格式：`https://你的帳號.github.io/repo名稱/`

## iOS 安裝為 APP

1. 用 **Safari** 打開網站
2. 點底部的 **分享按鈕**（方框+箭頭）
3. 選「**加入主畫面**」
4. 完成！全螢幕運作，跟原生 APP 一樣

## Android 安裝

1. 用 Chrome 打開網站
2. 點右上角選單 → 「安裝應用程式」

## 技術棧

- 純 HTML/CSS/JS，無框架、無需後端
- PWA (Service Worker + Web App Manifest)
- Google Sheets 作為免費可編輯資料庫
- Geolocation API 取得即時位置
- Google Maps 導航整合（大眾運輸模式）
