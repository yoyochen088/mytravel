# 🗺️ 旅遊助手 PWA

個人旅遊行程管理 PWA，手機優先設計，可安裝到 iOS/Android 主畫面當 APP 使用。

## 功能

- **現在行程** - 根據當前時間自動顯示你現在應該在哪、下一站去哪
- **時間軸** - 查看每天的完整行程，可切換日期
- **美食清單** - 獨立的美食列表，支援分類篩選與隨機推薦
- **隨機探索** - 彈性景點依分類隨機推薦
- **一鍵導航** - 根據你的 GPS 位置，開啟 Google Maps 規劃路線（大眾運輸模式）
- **AI 助手** - Gemini 3.1 Flash Lite 驅動，可問行程規劃、翻譯圖片（日文菜單/路標）
- **多用戶** - 選擇用戶後自動載入對應的 Sheet 和 API Key
- **離線支援** - Service Worker 快取，離線也能查看行程

## 架構

```
前端 (GitHub Pages)
  ├── 選擇用戶 → 打 Apps Script API → 取得 Sheet ID + API Key
  ├── 讀取行程/美食/景點 → Google Sheets (CSV)
  ├── AI 助手 → Gemini API (3.1 Flash Lite，備援 3.5 Flash Lite)
  └── 導航 → Google Maps URL
```

## 設定步驟

### 1. 建立「設定用」Google Sheet（管理者用）

這個 Sheet 存所有用戶的設定，**不需要公開**。

分頁名稱：`設定`

| 用戶名稱 | Sheet ID | API Key | 行程表分頁 | 隨機景點分頁 | 美食分頁 |
|---------|----------|---------|-----------|------------|---------|
| 小明 | 1vZYY... | AIza... | 行程表 | 隨機景點 | 美食 |
| 小華 | 2xABC... | AIza... | 行程表 | 隨機景點 | 美食 |

### 2. 部署 Apps Script

1. 在設定用 Sheet 裡：延伸功能 → Apps Script
2. 貼上 `apps-script/Code.gs` 的內容
3. 部署 → 新增部署 → 網頁應用程式
4. 執行身分：我自己
5. 存取權限：任何人
6. 複製部署 URL，貼到 `app.js` 的 `CONFIG_SCRIPT_URL`

### 3. 各用戶建立自己的行程 Google Sheet

每個用戶有自己的 Sheet，設為「知道連結的人可以檢視」。

需要以下分頁：

---

#### 📅 行程表（預設分頁名：`行程表`）

| 日期 | 開始時間 | 結束時間 | 地點 | 地址 | 備註 |
|------|---------|---------|------|------|------|
| 2026/7/28 | 09:00 | 11:00 | 台北101 | 台北市信義區信義路五段7號 | 觀景台記得預約 |
| 2026/7/28 | 12:00 | 13:30 | 鼎泰豐信義店 | 台北市信義區忠孝東路五段68號 | 小籠包必點 |

- 日期格式：`2026/7/28` 或 `2026-7-28` 都可以
- 時間格式：24小時制 `09:00`
- 地址越詳細導航越準確

---

#### 🎲 隨機景點（預設分頁名：`隨機景點`）

| 地點 | 地址 | 類型 | 備註 |
|------|------|------|------|
| 象山步道 | 台北市信義區信義路五段150巷 | 自然 | 日落很美 |
| 西門町 | 台北市萬華區西門町 | 逛街 | 週末人多 |

- 類型自訂名稱，APP 自動產生分類按鈕

---

#### 🍽️ 美食（預設分頁名：`美食`）

| 店名 | 營業時間 | 地址 | 類型 | 價位 | Google評分 | 是否排隊 | 推薦餐點 | 地區 | 備註 |
|------|---------|------|------|------|-----------|---------|---------|------|------|
| 一蘭拉麵 | 11:00-22:00 | 台北市信義區松壽路12號 | 拉麵 | $$ | 4.5 | 要排30分 | 天然豚骨 | 信義區 | 先抽號碼牌 |

- 類型自訂（拉麵、壽司、咖啡、甜點...），APP 自動歸類

---

### 4. 取得 Gemini API Key

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 申請（免費）
2. 填入設定 Sheet 的對應用戶 API Key 欄位

## 部署前端

1. GitHub 建立新 repo（Public）
2. 上傳所有檔案（不含 `apps-script` 資料夾）
3. Settings → Pages → Branch 選 main → Save
4. 等 1-2 分鐘上線

網址：`https://你的帳號.github.io/repo名稱/`

## 安裝為 APP

### iOS
1. Safari 打開網站
2. 分享按鈕 → 「加入主畫面」

### Android
1. Chrome 打開網站
2. 選單 → 「安裝應用程式」

## 更新 APP

1. 修改程式碼後推到 GitHub
2. `sw.js` 裡的 `CACHE_NAME` 版本號遞增（`v2` → `v3`）
3. 下次打開 PWA 會自動更新，不需重新安裝

## AI 助手

- 使用 Gemini 3.1 Flash Lite，備援 3.5 Flash Lite
- 自動讀取所有行程、美食、景點作為 context
- 支援文字對話 + 圖片翻譯（日文菜單、路標等）
- 對話記憶保留最近 20 則

## 技術棧

- 純 HTML/CSS/JS，無框架、無需後端
- PWA (Service Worker + Web App Manifest)
- Google Sheets 作為資料庫
- Google Apps Script 作為設定 API
- Gemini API（多模態：文字 + 圖片）
- Geolocation API 取得即時位置
- Google Maps 導航整合
