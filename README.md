# 🗺️ 旅遊助手 PWA

個人旅遊行程管理 PWA，手機友善，可安裝到 iOS/Android 主畫面當 APP 使用。

## 功能

- **現在行程** - 根據當前時間自動顯示你現在應該在哪、下一站去哪
- **時間軸** - 查看每天的完整行程
- **隨機探索** - 彈性景點隨機推薦
- **導航** - 一鍵開啟 Google Maps 導航（根據當前位置）
- **離線支援** - Service Worker 快取，離線也能查看行程

## 部署方式

這是純靜態網站，可部署到：
- **GitHub Pages** （免費）
- **Netlify** （免費）
- **Vercel** （免費）
- 或任何靜態網頁伺服器

### GitHub Pages 部署步驟：
1. 建立新的 GitHub Repository
2. 把這些檔案 push 上去
3. 到 Settings → Pages → Source 選 main branch
4. 等幾分鐘就能用了

## Google Sheets 設定

### 步驟：
1. 建立一個 Google Sheets
2. **分頁1（行程表）** 欄位格式：

| 日期 | 開始時間 | 結束時間 | 地點 | 地址 | 備註 |
|------|---------|---------|------|------|------|
| 2026/7/28 | 09:00 | 11:00 | 台北101 | 台北市信義區信義路五段7號 | 記得拍照 |

3. **分頁2（隨機景點）** 欄位格式：

| 地點 | 地址 | 類型 | 備註 |
|------|------|------|------|
| 象山步道 | 台北市信義區信義路五段150巷 | 自然 | 日落很美 |

4. 檔案 → 分享 → 發佈到網路
5. 選擇要發佈的分頁 → 格式選 CSV → 發佈
6. 複製產生的連結，貼到 APP 的設定頁面

### 注意事項：
- 每個分頁要分別發佈並取得各自的 CSV 連結
- 日期格式支援：`2026/7/28`、`2026-7-28`、`2026/07/28`
- 時間格式：`09:00`（24小時制）
- 地址越詳細，導航越精確

## iOS 安裝為 APP

1. 用 Safari 打開網站
2. 點底部的分享按鈕（方框+箭頭）
3. 選「加入主畫面」
4. 完成！像原生 APP 一樣使用

## Android 安裝

1. 用 Chrome 打開網站
2. 點右上角選單
3. 選「安裝應用程式」或「加到主畫面」

## 本地測試

需要 HTTPS 才能使用 PWA 功能，本地測試可用：

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx serve .
```

注意：本地 HTTP 環境下 Service Worker 和定位功能可能受限，部署到 HTTPS 後才能完整使用。

- Google Sheets 作為免費資料庫
- Geolocation API 取得位置
