# 🗺️ 旅遊助手 PWA

個人旅遊行程管理 PWA，手機優先設計，可安裝到 iOS/Android 主畫面當 APP 使用。

## 功能

- **現在行程** - 根據當前時間自動顯示你現在應該在哪、下一站去哪
- **時間軸** - 查看每天的完整行程，可切換日期
- **美食清單** - 獨立的美食列表，支援分類篩選與隨機推薦
- **隨機探索** - 彈性景點依分類隨機推薦
- **一鍵導航** - 根據你的 GPS 位置，開啟 Google Maps 規劃路線（大眾運輸模式）
- **AI 助手** - Gemini 3.1 Flash Lite 驅動，可問行程規劃、翻譯圖片（日文菜單/路標）
- **多用戶** - 選擇用戶後自動載入對應的 Sheet 和 API Key
- **離線支援** - Service Worker 快取，離線也能查看行程


## 安裝為 APP

### iOS
1. Safari 打開網站
2. 分享按鈕 → 「加入主畫面」

### Android
1. Chrome 打開網站
2. 選單 → 「安裝應用程式」

## 更新 APP

1. 修改程式碼後推到 GitHub
2. `sw.js` 裡的 `CACHE_NAME` 版本號遞增（`v2` → `v3`）
3. 下次打開 PWA 會自動更新，不需重新安裝

## AI 助手

- 使用 Gemini 3.1 Flash Lite，備援 3.5 Flash Lite
- 自動讀取所有行程、美食、景點作為 context
- 支援文字對話 + 圖片翻譯（日文菜單、路標等）
- 對話記憶保留最近 20 則
